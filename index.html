Upload Student List

Upload an Excel/CSV with columns Roll No, Enrollment, Name (an optional Batch column of A/B/C is honoured for CO-5-K). Choose the class first — the upload replaces the students of that class only and does not affect any other class. A login (username = password = enrollment) is created for each student.

Batch Setup (A / B / C)

Batches are decided by two roll-number cutoffs. Batch A = roll 1 to the first cutoff, B = up to the second cutoff, C = the rest. Set them and click Apply to auto-assign; you can then move individual students below.

Note: SPI attendance is not based on A/B/C — only the students you tick below under "SPI — Select Eligible Students" take part in SPI sessions.

SPI — Select Eligible Students

Seminar and Project Initiation Course (SPI) is taken by only a subset of the whole class (e.g. 20 students), not everyone. Tick the students enrolled in SPI below and Save. Only these students will show up when taking SPI attendance and in the SPI report — everyone else, and every other subject, is unaffected.

Students & Batch Assignment

Pick a class to view its students. Change any student's batch from the dropdown (batches apply to CO-5-K only; a manual change is marked ★ and survives re-applying cutoffs). Use Edit to change roll/name, Remove to delete a student (also removes their login).

Add a Subject

Define the subjects this app tracks attendance for. Subject Key is a short unique code used internally (e.g. OSY-TH, OSY-PR) — use -TH for theory and -PR for practical. Class / Semester must match the class name exactly as students were uploaded (e.g. CO-1-K or CO-5-K) — that is how the app decides which students appear when this subject is selected.
